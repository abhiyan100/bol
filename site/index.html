The loop

Hold right ⌥Global hotkey. Any app, any time.
SpeakLocal speech to text. Nothing leaves your Mac.
Say "send it"Bol pastes into your live Claude Code session.
Hear backWhen Claude finishes, Bol speaks a summary and flags failures.

Voice commands

"... send it"submits the prompt
"type git status"inserts text, no Enter
"scratch that"clears the input
"stop claude"interrupts the running turn
"go ahead"approves a permission prompt
"stop listening"sleeps until the next hotkey
